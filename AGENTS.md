# AGENTS.md

Guidance for AI coding agents working in this repository.

## Project Overview

Personal portfolio site of **Marco Bassaletti** (Senior Software Engineer), built with
[Docusaurus](https://docusaurus.io) **v2.3.1** (classic preset, React 17, JavaScript — not TypeScript).

- **Live site:** <https://mbassale.dev>
- **Hosting:** Cloudflare (proxied DNS) → droplet `137.184.116.147` (nginx), docroot
  `/var/www/mbassale.dev/html`
- **Deployment:** the production build (`build/`) is uploaded to the droplet docroot (see
  Deployment). `main` is the source of truth; the live site only changes when a build is
  deployed. Not GitHub Pages.

## Commands

```bash
npm install        # install dependencies (Node >= 16.14)
npm start          # dev server with hot reload (http://localhost:3000)
npm run build      # production build into ./build (fails on broken links)
npm run serve      # serve the production build locally
npm run clear      # clear Docusaurus caches (use when the dev server behaves oddly)
```

Always run `npm run build` before considering work done: `onBrokenLinks: 'throw'` means a broken
internal link or missing referenced asset **fails the build**.

## Repository Layout

| Path | Purpose |
|---|---|
| `docusaurus.config.js` | Site config: title/tagline, `url`/`baseUrl`, navbar, footer, prism themes |
| `sidebars.js` | Docs sidebar (autogenerated from `docs/`) |
| `docs/` | Docs plugin — currently just `resume.md` |
| `src/pages/` | Standalone pages; `index.js` is the homepage |
| `src/components/` | React components used by pages (`HomepageFeatures`) |
| `src/css/custom.css` | Global CSS / Infima theme overrides |
| `static/` | Copied verbatim to the site root (`img/` holds favicon, logo, feature art, social card) |

There is intentionally **no blog** — the blog plugin is not enabled in `docusaurus.config.js`.

## Content Conventions

### Docs (`docs/`)

- `docs/resume.md` has `docId: 'resume'` (from its path). The navbar item (`type: 'doc'`,
  `docId: 'resume'`) and footer link `/docs/resume` in `docusaurus.config.js` are coupled to it —
  update all three together if renaming or moving the file.
- Sidebar ordering uses `sidebar_position` frontmatter; page meta description uses the
  `description` frontmatter field.
- Admonitions use Docusaurus 2.x syntax with the title after the type, e.g.
  `:::warning Coming Soon!` (note: `warning` is a legacy alias of `danger` here — it renders
  `alert--danger` styling).

### Pages & components

- Homepage metadata (title/description) is set in `src/pages/index.js` via the `Layout` props.
- Site-wide tagline and title come from `docusaurus.config.js`.
- Homepage feature cards live in `src/components/HomepageFeatures/index.js`. External links
  inside JSX need explicit `target="_blank"` (Markdown links get it automatically; JSX does not).

## Deployment

```
npm run build
rsync -av --delete build/ mbassale@137.184.116.147:/var/www/mbassale.dev/html/
```

- `--delete` removes files removed from the site (e.g. retired pages) — drop it only if stale
  pages should stay live.
- DNS for `mbassale.dev` is proxied through Cloudflare to the droplet; nginx serves the docroot.
  There is no CI — deployment is a manual rsync.
- After deploying, verify: homepage bundle hash changed, removed routes return the 404 page.

## Notes for Agents

- Keep the dependency set minimal; Docusaurus 2.3.1 is intentionally pinned (see `package.json`).
- Do not edit files under `build/` (generated) or touch `package-lock.json` casually.
- MDX is active for `.md` files in `docs/`: `{` and `<` in prose must be escaped
  (`\{`, `\<`) or wrapped in code spans, or the build will fail.
