# portfolio

Marco Bassaletti's portfolio site — [mbassale.dev](https://mbassale.dev).

Built with [Docusaurus](https://docusaurus.io) and deployed to GitHub Pages from the `main` branch.

## Development

```bash
npm install
npm start        # dev server at http://localhost:3000
npm run build    # production build (also validates links)
npm run serve    # preview the production build
```

Requires Node >= 16.14.

See [AGENTS.md](AGENTS.md) for repository layout and content conventions.
